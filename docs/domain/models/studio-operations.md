# Studio 운영 기능의 축소
[현재 Studio 모델](studio.md) · [전환 계획](../../studio-simplification-plan.md)

Studio는 Project 상세정보·전체 ZIP 업로드·심사 요청·재요청·출시 요청·재요청를 제공한다.
CI 자격증명·OIDC 신뢰 정책, 내부 테스터 설치 권한, 빌드 웹훅과 커밋 상태 게시,
출시 채널·예약·롤백, 자동 빌드 보관 정리는 현재 Studio에서 제거했다.
과거 Flyway 테이블은 이관과 기록 확인을 위해 보존한다.

심사·출시 요청에 처리자·시각·피드백과 실패 사유를 기록한다.
서비스 간 이벤트 전달에는 공통 Outbox·Inbox와 재시도를 사용한다.
외부 결과는 요청 기록에만 반영하며 기존 운영 API에서 실패 이벤트를 재처리할 수 있다.
