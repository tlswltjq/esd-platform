# G5 PortOne 웹훅 수신 경계 검증

2026-11-05 현재 OCI 로컬 호스트에서 Payment의 웹훅 접수를 검증했다. 운영 코드·정책은 변경하지 않고 단위 검사 1건과 HTTP/DB 통합 검사 7건을 추가했다. 전체 앱 스택 대신 격리 MySQL·Kafka와 임의 포트의 Payment를 실행했다. 두 웹훅 테스트 클래스의 HTTP 바인딩은 127.0.0.1이다.

## 검증 범위

| 입력·상황 | 결과 |
|---|---|
| 서명 헤더 세 종류의 개별 누락·중복 | 401, 접수·재조회 예약·Outbox 불변 |
| 과거·미래 전달 시각 | 정확한 ±300초 허용, ±301초 401 |
| 복수 서명 | 잘못된 서명·미지원 버전과 함께 있어도 유효한 v1 서명 허용 |
| 원문 변조·크기 제한 | 공백만 추가해도 원래 서명은 401, 재서명한 정확한 64 KiB는 200, 초과는 413 |
| 서명된 잘못된 JSON | 중복 필드·뒤에 붙인 JSON은 400, 접수 없음 |
| 같은 ID·같은 원문 재전송 | 최초 접수 행 보존, 처리한 힌트를 다시 깨우지 않음 |
| 같은 ID·다른 원문 | 409 |
| 잘못된 상점·없는 결제·다른 결제 공급자 | 각각 400·404·409, 임의 업무 생성 없음 |
| 서명만 가진 다른 메서드·경로 | Payment 직접 요청은 401, 사용자·관리자 권한을 부여하지 않음 |
| SIMULATED 제공자 | 검증기 없음, 서명된 POST도 익명 401·MEMBER/ADMIN 403 |
| 비밀키 누락·빈 값·형식 오류 | 실제 PortOneConfiguration의 검증기 조립 거절 |
| 같은 알림의 동시 접수 | HTTP 요청 3개가 하나의 접수 행으로 수렴 |
| 접수 저장 후 DB 실패 | 접수·재조회 예약 동시 롤백, 같은 알림으로 재개 |
| 정상·지연·복구 알림 | 알림 자체는 결과를 확정하지 않음, 서버 조회 뒤 PAID·Outbox 한 번 확정 |

기존 공개 HTTPS edge의 다른 메서드 응답은 405다. 위 401 검사는 프록시를 거치지 않는 Payment 보안 경계이며 서로 다른 진입점을 구분한다. Gateway의 익명 허용·CSRF 예외는 추가하지 않았다.

PG HTTP는 테스트 JVM의 루프백 응답 서버다. 실제 PortOne 조회·승인·취소는 호출하지 않았고 운영 비밀값을 읽거나 교체하지 않았다. 활성 제공자의 기존 환불 웹훅 검사도 준비된 조회만 깨우며 환불 완료를 만들지 않는지 확인했다.

## 실행·최종 결과

```sh
./gradlew :apps:payment:test :apps:payment:compileIntegrationTestJava --no-daemon --max-workers=2 --console=plain
STOVE_TEST_MINIO_IMAGE=stove/minio:review-withdrawal-20261103 \
./gradlew :apps:payment:integrationTest --tests 'com.stove.payment.PortOneWebhook*IntegrationTest' --no-daemon --max-workers=2 --console=plain
```

MinIO는 이번 검사에 사용하지 않는다. 이 호스트의 기존 공급 이미지 선택은 공통 integrationTest 태스크의 불필요한 MinIO 빌드 의존성을 제외하기 위한 것이다. 다른 호스트에서는 준비한 공급 이미지를 지정한다.

최종 XML은 Payment 단위·아키텍처 381건과 두 웹훅 클래스의 통합 20건이며 실패·오류·건너뜀은 모두 0건이다. 실행별 중복 합산은 하지 않았다. 최초 통합 실행은 새 비활성 검사에 모의 PG 키 설정을 빠뜨려 1건 실패했고, 테스트용 루프백 주소·고정 픽스처 키를 명시한 뒤 두 클래스 20건을 재실행해 통과했다. 운영 설정은 변경하지 않았다.

검증 전후 기존 컨테이너 23개의 ID·실행 상태·시작/종료 시각·재시작 횟수와 볼륨 57개가 일치한다. 검증 컨테이너는 모두 종료·정리됐고 새 실행 중 컨테이너는 없다. 앞선 외부 주입 작업의 미커밋 파일 네 개도 SHA-256 대조로 보존을 확인했다.

## 남은 범위

이번 결과는 Payment 직접 수신 경계의 검증이다. 공개 HTTPS·인증서 갱신·실제 제공사 전송·배포 도구의 PortOne 키 주입과 운영 비밀 교체는 재검증하지 않았다. 기존 공개 edge 컨테이너는 중지 상태로 보존했다. 전체 Payment check·migrationTest·전체 구매/환불 여정을 실행한 결과로 확대하지 않는다. G5 전체는 미완료이며 다음은 기존 경보·실패 재처리의 남은 범위 점검이다.
